    About this contract

    Listings are stored as JSON documents and exposed to KW applications, including Command. The contract unifies data from hundreds of listing sources, so which fields are required or optional can change between versions. Check the version above against the one you’re building to.

    Allowed values marked as KW-defined are normalized after ingestion. Send the closest matching value your system has; KW maps it to the standard value where a normalization rule exists.
